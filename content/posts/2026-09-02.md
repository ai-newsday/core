### GenFirst：生成先于重建，实现稳定端到端潜在生成

潜在生成模型通常分两阶段训练：先训练变分自编码器重建，再在冻结的潜在空间上训练生成模型。但重建优化的潜在空间未必适合生成，联合训练面临潜在崩溃和生成-重建冲突。研究者分析发现，KL散度中的熵项能防止崩溃，且重建与生成存在不对称学习动态。基于此，团队提出GenFirst策略：生成目标先在弱重建压力下塑造潜在空间，再逐步加强重建以恢复细节。该方法在连续自回归先验和SiT先验上验证有效，可直接替代传统两阶段训练流程。

### NoRA 改进 LoRA：无需额外参数即可加速收敛、提升训练稳定性

研究者提出 Normalized Low-Rank Adaptation（NoRA），对 LoRA 的 down-projection 矩阵进行归一化处理。由于 LoRA 将 up-projection 初始化为零，早期优化动态主要由 down-projection 决定，NoRA 利用这一特性，在训练期间或仅在初始化时归一化 down-projection。实验覆盖预训练、监督微调和强化学习，结果显示 NoRA 能加速收敛、提升性能与训练稳定性，并缓解灾难性遗忘。

### Hermes Agent v0.21.0 发布：Bot Mode 让多 Agent 像团队一样协作

NousResearch 发布 Hermes Agent v0.21.0（v2026.8.31），自 v0.20.0 以来累计约 5,800 个提交、760 余位贡献者。核心更新 Bot Mode 内置于桌面应用：每个 Agent 拥有独立名称与头像，支持创建群组聊天，多个 Bot 可在同一房间对话。此外，cron jobs 获得记忆与连续性，subagent 支持飞行中实时引导，MCP 接口升级为命令中心，Agent 现在可驱动桌面浏览器。
