# AI Daily · 2026-09-01

> **今日看点**：今日亮点：GLM-5.3凭后训练超越GPT-5.6 SOL与Claude Fable 5，开源权重模型并列第一；ChatGPT广告年收入达10亿美元，正向全球扩展；PTD将视频定位延迟降低79倍，4B模型并行解码。详见正文，参考链接见文末。

### LoopArena：评测模型作为循环工程控制器，最佳成功率仅24.69%

LoopArena是一个benchmark，用于评估模型作为运行时控制器在Loop Engineering中的表现。Loop Engineering是一种围绕coding agents组织开发工作的实践，practitioners设计循环来监控进度、分配工作、运行检查并决定agent下一步操作。该benchmark通过三种评估类型测试模型指导独立coding agent的能力。

### DART-SD：拓扑感知自蒸馏解决多轮工具调用Agent的轨迹坍缩问题

研究者提出DART-SD框架，用于多轮工具调用Agent的自蒸馏训练。该方法将执行过程建模为交互状态转换图（ISTG），识别关键拓扑断点（CTB）并检索成功恢复参考，通过CTB引导的局部监督进行渐进式自蒸馏，仅在恢复步骤计算训练损失，保护有效推理前缀免受破坏性梯度更新。对从业者而言，这为构建多目标子任务Agent提供了新训练范式，避免传统全轨迹模仿导致的策略多样性退化。

#多轮工具调用 #自蒸馏 #Agent训练
[2]

### Puro-2B：$5090内用RTX 5090训练，逼近Qwen2.5-1.5B性能

团队开源了一套低成本预训练方案，在消费级RTX 5090上用FP8精度从头训练Puro-2B系列模型，最高处理1.4万亿token，最佳模型成本低于$6.9K，性能逼近Qwen2.5-1.5B。团队还据此推导出Puro Cost Scaling Law，拟合结果显示约$4.4K即可达到Qwen2-1.5B水平。该方案为个人或小团队复现开源模型提供了可行路径。

#Puro-2B #RTX5090 #预训练
[3]

### DeepSeek-V4-Flash-Vision-Exp 推出：V4系列首个多模态实验模型，Agent能力跃升

DeepSeek发布DeepSeek-V4-Flash-Vision-Exp，这是DeepSeek-V4系列的首个实验性多模态模型。该模型在DeepSeek-V4-Flash架构基础上加入视觉模块并经过持续训练，多模态agent能力相比DeepSeek-V4-Flash-0731大幅提升，同时文本agent任务性能保持相当。在ApexBench上得分36.5，较基线26.2提升超10个百分点。

#DeepSeek #多模态 #Agent
[4]

### Runway 推出 Solaris：首个 Interface World Model，实时生成交互界面

Runway 推出 Solaris，自称首个 Interface World Model。该系统能逐帧实时生成交互界面，全程无需编写代码。据官方数据，在结构相似性和信息保留两个指标上，Solaris 的表现优于当前前沿大语言模型。这意味着设计师或开发者可以借助它快速生成界面原型，降低交互设计的技术门槛。

#Runway #Solaris #InterfaceWorldModel
[5]

### AWS Agent Registry 正式上线：企业级 Agent 与工具统一目录

AWS Agent Registry 现已正式发布，为企业提供统一的 Agent、工具、技能和自定义资源目录。该服务支持搜索、治理和发现工作流，帮助企业规模化地管理 AI Agent 生态。对从业者而言，这意味着可以在组织内集中发布、审核和发现 Agent 资源，降低重复建设成本，提升企业级 AI 应用的可维护性。

#AWS #Agent #企业AI
[6]

### H3 Max Live 推出：视频生成快于实时，聊天即可导演无限直播

fal 推出 H3 Max Live，视频生成速度突破实时限制，实现每帧即时生成的无限直播。用户通过输入 !prompt 指令，场景可在数秒内呈现。该技术将视频生成与聊天交互结合，为需要实时内容生产的创作者提供了新工具。
