# AI Daily · 2026-09-01

### LoopArena 评测：模型当循环控制器，全任务严格成功率仅 24.69%

LoopArena 是一项针对 Loop Engineering 的基准测试，用于评估一个模型（Controller）能否有效引导另一个固定的编码智能体（Worker）完成长周期任务。测试分三种类型：Type I 通过执行验证问题评估下一步指令选择，Type II 在任务切片上执行重复控制，Type III 在完整任务上评估端到端表现。实测结果显示，在完整任务上最佳严格成功率仅为 24.69%，表明长周期循环控制仍有较大提升空间。

### DART-SD：拓扑感知检索与微调，解决多轮工具调用Agent自蒸馏难题

论文提出DART-SD框架，用于多轮工具调用Agent的自蒸馏训练。该方法将执行过程建模为收敛的交互状态转移图（ISTG），捕捉成功与失败探索路径的菱形拓扑结构。通过识别关键拓扑断点（CTB）并检索成功恢复参考，实现渐进式自蒸馏——仅在生成的恢复步骤上计算训练损失，保护有效推理前缀免受破坏性梯度更新。对从业者而言，这为构建多轮工具调用Agent提供了新的训练范式，避免传统轨迹模仿导致的策略多样性下降。

### Puro-2B：RTX 5090上以不到$5090成本复现Qwen2-1.5B性能

研究者提出开源预训练配方Puro-2B，使用消费级RTX 5090 GPU以FP8精度训练1.4万亿token，最佳模型成本低于$6.9K，性能接近Qwen2.5-1.5B。技术组合包括低精度训练、超球优化、课程模型平均和数据配方。研究还推导了Puro Cost Scaling Law，拟合结果表明约$4.4K即可达到Qwen2-1.5B性能水平。该配方为学术和开源社区提供了低成本大模型训练路径。

### DeepSeek-V4-Flash-Vision-Exp 上线：多模态 Agent 能力跃升 39%

DeepSeek 发布 DeepSeek-V4-Flash-Vision-Exp，这是 DeepSeek-V4 系列的首个实验性多模态模型，在 DeepSeek-V4-Flash 架构基础上加入视觉模块并持续训练。与 DeepSeek-V4-Flash-0731 相比，多模态 Agent 能力显著提升：ApexBench (Pass@1) 从 26.2 升至 36.5，ZeroBench (Pass@5) 达 35.0，Chartography 达 64.3。

### Runway 推出 Solaris：首个 Interface World Model，实时生成交互界面，性能超越前沿 LLM

Runway 发布 Solaris，这是其首个 Interface World Model，能够逐帧实时生成交互式界面，全程无需编写代码。官方测试显示，在生成新界面时，Solaris 在结构相似性和信息保留两项指标上均优于当前前沿 LLM。对从业者而言，这意味着界面原型开发可能从编码转向自然语言描述，大幅降低交互设计门槛。

### AWS Agent Registry 正式上线：企业级 Agent 与工具统一目录

AWS Agent Registry 现已正式发布，为企业提供统一的搜索型治理目录，集中管理跨组织的 Agent、工具、技能和自定义资源。该服务涵盖发布、策展和发现工作流，并考虑企业级治理需求。对从业者而言，这意味着可在 AWS 生态内规模化地组织和管理 AI Agent 资产，降低多 Agent 协作的复杂度。

### OpenMAIC v1.0 登顶 GitHub Trending：一键生成 AI 课堂，VoxCPM 驱动语音克隆
