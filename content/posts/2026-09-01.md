# AI Daily · 2026-09-01

> **今日看点**：Agent 能力进入「验证期」——LoopArena 显示最佳模型引导编码成功率仅 24.69%，长程任务仍被记忆膨胀和轨迹坍缩卡住脖子，但 DART-SD、ContextPilot、Meta^n 等研究正在从蒸馏、RL、元操作三个方向同时突围。多模态 Agent 迎来拐点：DeepSeek-V4-Flash-Vision-Exp 与 VLAct、INDI 等方案让 VLA 在固定数据下反超工业级系统，Code-as-World 进一步证明 VLM 推理已能匹敌专有模型。企业级基础设施从「能用」走向「可信」——AWS Agent Registry 上线、Bedrock 多租户隔离、7 层可观测性、Dify 多渠道复用，Agentic Harness 正成为企业信任的关键抓手。模型训练门槛持续下探：Puro-2B 用一张 RTX 5090 逼近 Qwen2.5-1.5B，GLM-5.3 靠 post-training 在开放权重中并列第一，证明训练扩展比堆参数更值钱。应用层开始兑现商业价值——学生一周搭出肽追踪 App 月入 13 万美金，Meshy 3D Agent 线下试玩，Runway Solaris 让界面本身成为可生成对象，AI 原生产品形态正在成型。

### LoopArena 评测：最佳模型引导编码 Agent 成功率仅 24.69%

Loop Engineering 是一种围绕编码 Agent 组织开发工作的实践，通过设计循环来监控进度、分配任务并决定下一步操作。研究者推出 LoopArena，用于评估一个模型（Controller）引导独立编码 Agent（Worker）完成长周期任务的能力。评测分三种类型：Type I 通过执行验证问题评估下一步选择，Type II 在任务切片上执行重复控制，Type III 在完整任务上评估。

### DART-SD：拓扑感知自蒸馏，破解多轮工具调用Agent的轨迹坍缩难题

多轮工具调用是构建自主Agent的关键能力，但现有方法依赖完整轨迹模仿，导致拓扑坍缩。DART-SD提出拓扑感知自蒸馏框架，通过ISTG建模执行过程，识别关键拓扑断点并检索恢复参考，采用渐进式自蒸馏范式，仅在生成的恢复步骤上计算训练损失，保护有效推理前缀。该框架有望提升多轮工具调用Agent的训练效率和策略多样性。

### Puro-2B：$5090 内用 RTX 5090 训练出接近 Qwen2.5-1.5B 的模型

研究者提出 Puro-2B 开源预训练方案，在消费级 RTX 5090 上以 FP8 精度训练 1.4 万亿 token，最佳模型成本低于 $6.9K，性能逼近 Qwen2.5-1.5B。方案结合超球优化、课程模型平均和数据配方等技术，并推导出 Puro Cost Scaling Law，拟合结果显示约 $4.4K 即可达到 Qwen2-1.5B 水平。对独立研究者和开源社区而言，这为低成本复现主流模型提供了可行路径。

### DeepSeek-V4-Flash-Vision-Exp 上线：多模态 Agent 性能跃升，文字能力持平

DeepSeek 发布 DeepSeek-V4-Flash-Vision-Exp，这是 DeepSeek-V4 系列首个实验性多模态模型。该模型在 DeepSeek-V4-Flash 架构基础上加入视觉模块并进行持续训练。测试数据显示，其多模态 Agent 能力显著提升，ApexBench 得分 36.5，较前代 26.2 大幅提升；同时文字 Agent 任务性能保持相当，Terminal Bench 2.1 达 83.9。

目前已知 x.com 等平台跟进支持。
