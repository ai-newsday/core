# OpenAI 推 ChatGPT Images 2.5 | GLM-5.3 Flash 成本降 82%【AI日报】

> 今日亮点：OpenAI 推 ChatGPT Images 2.5，草图变精修图；GLM-5.3 Flash 成本降 82%；寒武纪、阿里加入 PyTorch 基金会；详见正文，参考链接见文末。

## OpenAI 推出 ChatGPT Images 2.5：把草图与参考照变成个性化精修图

OpenAI 推出 ChatGPT Images 2.5，可将用户的想法、草图和参考照片转化为更个性化、更精致的图像，更好地反映用户的创意。该功能升级了图像生成能力，让用户能基于个人素材获得更贴合预期的视觉输出。

## Dr. Claw：把 AI 研究流程封装成可审计、可恢复的工作空间

![](https://arxiv.org/html/2609.00365v1/figures/vibelab-layered-framework.png)

Dr. Claw 是一个开源工作空间，将 Claude Code、Gemini CLI 等命令行编码代理包装成可控且可审计的人机协作流程。它通过持久化状态对象、可复用技能库和多执行器协调，把规划、执行和写作整合成可追溯的闭环。评估显示，在保持执行器不变的情况下，Dr. Claw 在研究完整性上得分更高，同时保留完整的决策轨迹。对 AI 研究者而言，这意味着可以将研究过程标准化并留存可审计记录，替代过去分散在 chat、IDE、终端和写作工具中的碎片化流程。

## 寒武纪加入 PyTorch 基金会，成为白金会员

PyTorch 基金会宣布，寒武纪（Cambricon）已加入成为其白金会员。寒武纪成立于 2016 年。

#PyTorch #寒武纪 #白金会员

## 阿里、寒武纪成PyTorch基金会Platinum成员，蚂蚁、华为也加入

阿里巴巴云、寒武纪成为PyTorch Foundation的Platinum成员，蚂蚁集团和华为也加入该基金会。此次合作在上海举行的PyTorch Conference China上宣布。中国头部AI企业集体加入PyTorch生态，意味着国内开发者将更深度参与开源AI框架的演进，同时也能获得更贴合本土硬件（如寒武纪芯片）的优化支持。

## 手机里的 3D 工厂：Meshy AI 应用上线，照片直出可打印模型

![](https://i.ytimg.com/vi/i0ObbI3FqrE/sardefault.jpg?sqp=-oaymwEkCJUDENAFSFqQAgHyq4qpAxMIARUAAAAAJQAAyEI9AICiQ3gB&amp;rs=AOn4CLDvShYiEJyxxrq7MA8HXnFnr1ATqw)

Meshy AI 应用正式发布，用户可在应用商店搜索「Meshy AI」或扫描官网二维码下载。该应用支持将照片转换为 3D 模型，并可直接用于打印。对 3D 设计、游戏开发等从业者而言，这提供了一个移动端快速生成 3D 资产的途径，降低了 3D 内容创作门槛，让非专业用户也能在手机上完成从照片到可打印 3D 模型的流程。

## Claude Opus 5 在 Coding Agent 基准测试中仅过 23.9%，人类专家得分 82.2%

![](https://pbs.twimg.com/media/HRpHvHZaUAA9lEP.png:large)

一篇关于 coding agents 的 benchmark 论文显示，Claude Opus 5 在 Claude Code 环境下运行，仅通过 23.9% 的评估项，而专家人类参考得分 82.2%。该测试将开发者 agent 置于真实客户项目中，要求处理完整工作记录。当前 coding agent 在复杂工程任务上的能力上限已被量化，企业若引入此类工具，仍需保留大量人工审核环节，23.9% 的通过率意味着自动化程度远未达到可独立交付的水平。

#CodingAgent #Benchmark #Claude
[6]

## 同分不同价：GLM-5.3 Flash 智力指数追平 GPT-5.6 Terra，成本直降 82%

![](https://pbs.twimg.com/amplify_video_thumb/2097031685498138624/img/boFjK786UUlAtkUx.jpg)

Together Compute 在 X 平台发布数据，GLM-5.3 Flash 与 GPT-5.6 Terra 在 Artificial Analysis 的智力指数上得分相同，但 Flash 每个任务的成本仅为后者的 18%。对开发者而言，这意味着在同等智能水平下，选择 GLM-5.3 Flash 可将推理成本压缩至 GPT-5.6 Terra 的五分之一左右，适合对成本敏感的生产场景。

#GLM-5.3 #GPT-5.6 #成本优化
