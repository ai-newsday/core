## 论文

### Kimi K3 2.8T MoE 模型登场：1040 亿激活参数，百万 token 上下文，推理效率提升 2.5 倍

Kimi K3 是一款拥有 2.8 万亿参数、1040 亿激活参数的混合专家（MoE）模型，原生支持视觉能力，上下文窗口达百万 token。基于 Kimi Delta Attention 与 Attention Residuals 架构，结合 Stable LatentMoE 技术，每 token 激活 16 个专家，整体扩展效率较 K2 提升约 2.5 倍。后训练阶段涵盖通用、代理与编码领域的强化学习，支持多推理层级，实现组合泛化与长程任务执行。

### 扩散蒸馏新解：正负分支不对称致模型失效，PDM方法提升视频控制鲁棒性

研究者发现，在基于策略扩散蒸馏（OPD）中，若教师模型在无条件分支保留学生不可见的特权信息，会导致正负分支误差相互抵消的负分支不对称（NBA）问题，使传统速度匹配失效。为此，团队提出正方向匹配（PDM）方法，分别约束正向预测与条件方向，避免误差补偿。该方法在稀疏视频控制任务中验证，相比 naive 匹配对推理引导尺度更敏感，PDM 实现更稳健的知识迁移。对从业者意味着：在使用 CFG 与蒸馏结合时，需关注分支信息对称性，PDM 可作为优化策略提升生成稳定性。

#扩散模型 #知识蒸馏 #视频生成
来源 [hf-papers](https://huggingface.co/papers/2607.24731) · 93 分

### RARG：让相关性指导 Agent 的 Corpus 交互，提升搜索收敛速度

研究者提出 Relevance-Aware RipGrep Search Agent (RARG)，将相关性作为执行先验指导语料库交互。该方法通过由粗到细的相关性引导，优化文档遍历顺序、初始化入口点并重排序 grep 匹配结果，使 LLM 优先看到高价值片段。在复杂问答与推理检索任务中，RARG 提升了准确率与效率的平衡。对从业者而言，这意味着在构建 Agent 搜索系统时，不应仅用相关性筛选文档，更应将其融入交互过程以加速收敛。

### LiquidAI 发布 LFM2.5-Encoder-350M：多语言双向编码器，8k 上下文，15 语言支持，高效推理

LiquidAI 推出 LFM2.5-Encoder-350M，基于 LFM2 架构的多语言双向掩码语言模型，支持 15 种语言，具备 8k 上下文长度，适用于分类、检索、语义相似度等下游任务。该模型在同类尺寸中表现领先，推理效率媲美 ModernBERT，适合 CPU 端部署。开发者可通过 Hugging Face Space 体验零样本提示路由等 demo，适用于多语言 NLP 场景的模型微调与边缘部署。

### Kimi-K3 GGUF开源：2.8T参数百万token上下文，长程编码能力突破

Unsloth团队在Hugging Face发布Kimi-K3的GGUF量化版本，该模型基于Kimi Delta Attention（KDA）和Attention Residuals（AttnRes）架构，参数量达2.8万亿，支持1百万token上下文窗口，是全球首个开源3T级多模态智能体模型。其Stable LatentMoE框架激活896个专家中的16个，效率较K2提升约2.5倍，适用于长程代码生成、知识工作与复杂推理任务。
