# AI Daily · 2026-08-27

### GigaBrain-0.7发布：三系统架构+3.7万小时数据，具身AI能力跃升

GigaBrain-0.7是新一代具身基础模型，采用三系统架构统一视觉-语言-行动理解，预训练数据扩展至3.7万小时异质具身数据，并引入单阶段对齐训练联合优化多模态理解与多形态机器人动作生成。相比前代及π_0.5等SOTA模型，在零样本基础能力、语言指令遵循和任务成功率上均有显著提升，已在Maker H01等平台验证家庭与工业场景适应性。训练代码与模型权重将开源。

### 标注即rollout：视频MLLM强化学习提速2倍，解码快37倍

研究者提出OraRL，将标注直接作为oracle rollout融入强化学习后训练，解决视频多模态大模型（Video MLLM）样本效率低的问题。该方法通过解耦优势估计器避免优势反转，仅需SFT 2.2倍步时间，远低于GRPO+CoT的4.9倍。Video-ORA-9B无CoT时解码仅需130ms（GRPO需4780ms），temporal mIoU从62.5提升至66。对从业者而言，这意味着在视频理解任务上可用更低延迟获得更强模型。

### AutoSaddler：让LLM Agent harness自动进化，3个基准提升超9个百分点

LLM agent在长程任务中容易因小错误累积而失败，而外部harness（辅助框架）能提升鲁棒性，但设计依赖人工且成本高昂。研究者提出AutoSaddler，将harness改进建模为离线学习问题，通过失败轨迹诊断、结构化补丁生成和验证选择实现自动迭代优化。在GAIA2、SWE-Bench Pro和Terminal-Bench 2.0上分别提升9.0、9.6和10.0个百分点。消融表明深度调试、针对性修改和泛化感知选择是关键。为agent可靠性工程提供了可复用的自动化路径。

### Qwen3.8-Flash-Next 架构预览：QSA 稀疏注意力大幅降低长上下文延迟

Qwen3.8-Flash-Next 是 Qwen4 底层架构的实验性预览，由 Qwen 团队发布。其核心创新在于 Hybrid Attention with QSA——将 Gated DeltaNet 与 Qwen Sparse Attention 配对，QSA 在 micro-block 级别而非单个 token 上操作，显著削减长上下文推理延迟。同时引入 Gated Residual 机制以改善深层 LLM 训练稳定性。

### GLM-5.3-Flash 发布：320B 参数模型仅 18B 激活，推理成本降至前代 1/10

智谱发布 GLM-5.3-Flash，这是 GLM-5 系列首款原生多模态模型，采用 320B 总参数与 18B 激活参数的 MoE 架构。模型引入稀疏与线性注意力混合架构，并结合 mHC 技术提升扩展效率，基于 30T token 多模态语料训练。在编码与 agentic 基准上接近 Claude Opus 4.8，推理成本仅为 GLM-5.2 的十分之一。Unsloth 提供 GGUF 量化版本，从业者可在本地高效部署。

### 苹果PROOF-Gen：用优化数据替代盲目筛选，让工具调用蒸馏效率翻倍

苹果ML团队发布PROOF-Gen方法，针对工具调用能力蒸馏中的generate-and-filter机制进行优化。当前蒸馏流程每日或每周重跑教师模型轨迹，但57%的教师试验在τ2-bench上失败，其中三分之二为near-miss场景（工具调用基本正确却被意外撤销）。PROOF-Gen通过优化数据而非单纯筛选，保留失败轨迹中的有效信号，降低对前沿教师模型的重复调用成本。
