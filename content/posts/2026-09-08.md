# Iris-mini/pro 用 SFT-RL 爬升智能体性能 | MiniCPM5 拿下 15 分成榜首【AI日报】

> 今日亮点：Iris-mini/pro 用 SFT-RL 交替爬升智能体性能；MiniCPM5 以 2.6B 参数拿下 15 分成榜首；腾讯开源 TeamAI-CLI 用 Git 统一 Agent 知识库；

## Iris-mini/pro：用 SFT-RL 交替爬升搜索智能体性能

![](https://arxiv.org/html/2609.04304v1/BrowseComp.png)

团队提出 Iris-mini（35B-A3B）和 Iris-pro（397B-A17B）两个搜索 agent，任务从 web 语料的超链接结构反向构建：在实体图上生成多跳链，将非答案实体改写为描述性引用以杜绝字符串匹配，仅保留参考模型闭卷失败但提供证据后可解的问题。训练采用 SFT-RL climbing——每轮 RL 结束后将最难且最高效的 rollout 送回下一轮监督微调。所有结果来自单一 ReAct agent，无子 agent 也无测试时验证。

## 语言模型用信心信号驱动决策：研究者证明可被操控

![](https://media.springernature.com/m685/springer-static/image/art%3A10.1038%2Fs42256-026-01293-x/MediaObjects/42256_2026_1293_Fig1_HTML.png)

Kumaran等人发表在Nature Machine Intelligence的研究表明，大型语言模型在决定何时回答问题或选择回避时，依赖信心信号驱动行为。研究者通过增强或抑制信心信号，成功影响了模型的回避决策。这为控制模型回答倾向提供了新干预手段。

#大语言模型 #AI安全 #研究论文

## 腾讯开源 TeamAI-CLI：内部使用数月，用 Git 统一 Agent 知识库

![](https://pbs.twimg.com/card_img/2097101712180019200/UddbNxUS?format=jpg&amp;name=orig)

腾讯近日开源了 TeamAI-CLI，该工具自三月起已在内部使用。它把团队知识（技能、规则、文档）集中到一个 Git 仓库中，所有 AI agent 都基于同一份手册工作，变更通过合并请求（MR）进行。这种以代码仓库管理 agent 行为规范的思路，让多 agent 协作时知识保持一致，团队可以像管理代码一样迭代 agent 指令，用 MR 流程控制上线，取代了手动同步多个 agent 配置的繁琐做法。

#Agent协作 #Git #开源
[3]

## 5秒视频1.653秒生成：NVIDIA Sol 开源 MiniMax-H3 加速方案

![](https://pbs.twimg.com/profile_images/1875100548535574529/VxHk9HyU_400x400.jpg)

NVIDIA Sol 团队为 MiniMax-H3 视频生成模型提供加速推理方案 Sol-H3，在单台 8× NVIDIA B300 Blackwell 系统上，5 秒 1344×768 分辨率视频仅需 1.653 秒推理时间，速度超过播放速度。该方案已完全开源，并通过 Reactor API 提供在线体验入口，用户无需自备 GPU 即可测试。

#视频生成 #MiniMax-H3 #NVIDIA

## 2.6B 模型拿下 15 分：MiniCPM5 成 4B 以下开源模型 Intelligence Index 榜首

![](https://pbs.twimg.com/profile_images/1503637999535284230/ZflGAHZW_400x400.jpg)

OpenBMB 团队宣布，其 MiniCPM5-2B 模型在 Artificial Analysis Intelligence Index v4.2 评测中取得 15 分，成为总参数量低于 4B 的所有开源权重模型中的最高分。该模型参数量为 2.6B，团队表示优化重点在于兼顾 agentic 性能与 token 效率。这一成绩意味着在资源受限场景下，开发者可以直接选用该模型替代更大体量的开源方案，无需额外微调即可获得领先的智能表现。

#MiniCPM5 #OpenBMB #模型评测
[5]

## RWKV-7 G1j 新增 SVG prompts 测试功能，G1k 训练版细节更强

![](https://pbs.twimg.com/media/HRmIY4ua0AAUYWc.jpg:large)

BlinkDL 团队在 RWKV-7 G1j（100% RNN 架构）中开放了 SVG prompts 测试入口，用户可通过链接直接在平台验证模型生成 SVG 图像的能力。G1j 在 agent、coding、STEM 等任务上表现提升明显，但绘制复杂细节（如鸟类）仍超出当前能力范围。G1k 训练版本在细节处理上略有改进，团队表示将继续迭代优化。

#RWKV #SVG #AI绘图

## Motus2：单一模型闭环预测、评估与策略改进，用于灵巧操作

![](https://pbs.twimg.com/media/HRkrgTdXMAEZyTK.jpg:large)

Motus2是一种自进化的通用世界模型，用于灵巧操作任务。大多数机器人世界模型难以在预测、评估和策略改进之间形成闭环，而Motus2通过单一共享模型同时承担策略、模拟器和价值函数的角色，使模型能够自主提出动作建议并持续优化。这意味着灵巧操作系统的模型组件可以从多个减少到单一，降低系统复杂度和部署成本。

#机器人 #世界模型 #灵巧操作
[7]

## VoxCPM 微调出土耳其语音合成模型 Kahya-TTS

![](https://pbs.twimg.com/profile_images/1503637999535284230/ZflGAHZW_400x400.jpg)

OpenBMB 账号转发土耳其开发者 @AlicanKiraz0 的消息：其在开源语音模型 VoxCPM 基础上完成多轮微调，推出 Kahya-TTS，可生成流畅且带强调语调的土耳其语语音。模型名称致敬已故艺术家 Ayhan Kahya。OpenBMB 表示期待该项目开源。开源语音模型的可定制性在此得到体现，多语言 TTS 开发门槛进一步降低。

## HiDream-O1-Embodied 发布即登顶，RoboColiseum 鲁棒性榜单得分 0.692

HiDream 团队发布 HiDream-O1-Embodied 具身世界模型，在 RoboColiseum 鲁棒性榜单排名第一，得分 0.692，在真实世界不可预测性测试中超越其他模型。该模型针对具身 AI 在复杂环境中的稳定性进行了优化，为机器人任务规划与执行提供了新的基准参考。

## MiniCPM5-2B 登陆 SGLang：RTX 5090 上解码超 250 tok/s

![](https://pbs.twimg.com/profile_images/1503637999535284230/ZflGAHZW_400x400.jpg)

OpenBMB 团队宣布 MiniCPM5-2B 模型已支持 SGLang 部署，SGLang 提供 day-0 服务支持，兼容 RTX PRO 6000、RTX 5090、DGX Spark 和 Hopper 系列显卡。在 RTX 5090 上，以 bs=1 运行 coding 任务时，解码速度超过 250 tok/s/user。这意味着开发者可以在单张消费级显卡上高效运行中型语言模型，无需依赖多卡集群或云端 GPU 实例。

#MiniCPM5-2B #SGLang #RTX5090
[10]

## vLLM Day-0 支持 MiniCPM5-2B：2.6B 模型原生 131K 上下文 + Tool Calling

![](https://pbs.twimg.com/profile_images/1503637999535284230/ZflGAHZW_400x400.jpg)

vLLM 项目已为 OpenBMB 发布的 MiniCPM5-2B 模型提供 Day-0 支持。该模型为 2.6B 参数的 Dense 架构，原生支持 131K 上下文长度，且 Think 与 No-Think 模式共享同一 checkpoint。通过 vLLM 内置的 minicpm5 parser，开发者可直接调用 Tool Calling 功能。

## LinkedIn 论文聚焦 Agent 记忆可移植性：构建智能体的关键挑战

![](https://pbs.twimg.com/media/HRn81Q8aYAATC3n.png:large)

LinkedIn 发布了一篇关于 Agent 记忆的新论文，核心探讨记忆是否可移植。该论文指出，记忆是构建智能体时最难优化的部分之一，而可移植性对于跨系统复用记忆至关重要。目前公开信息仅透露了这一研究方向，具体实现方案和实验结论需查阅原文。
