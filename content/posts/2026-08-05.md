## 论文

### LLM Agent长周期任务准确率翻倍：LongHorizon-Harness框架解析

LLM Agent在执行长周期任务时，常因状态追踪困难和错误自我评估传播导致性能下降。研究者提出LongHorizon-Harness，将任务状态显式维护在执行外部，仅更新从环境独立验证的事实。其Manage-Execute-Audit循环包含状态管理器、执行器和只读审计器，配合AgentAdapter支持模型与框架互换。

### Skill-α：用强化学习让 Agent 技能生成提升 6.7 点

研究者提出 Skill-α，一种基于强化学习的渐进式 Agent 技能生成方法。该方法将技能构建拆解为可独立评估的序列编辑过程，并引入“回滚奖励”机制，通过对比编辑前后在下游任务的表现来优化技能质量。实验显示，在 GPT-4o 环境下，该方法在 CL-Bench 和 tau2-bench 上分别比最强基线提升 3.3 和 6.7 个百分点。这对开发者意味着无需依赖特定启发式规则，即可利用下游反馈自动迭代出更高效的 Agent 技能模块。

#ReinforcementLearning #AgentSkills #SkillGeneration
来源 [hf-papers](https://huggingface.co/papers/2608.01678) · 92 分

### UEmbed统一稀疏与稠密多模态嵌入，一次前向传递搞定双路检索

UEmbed是一个decoder-only多模态嵌入模型，能在一次因果前向传递中同时生成稀疏词汇和稠密表示。研究者在公开数据上训练了2B、4B、9B三种规模，其中9B版本在MMEB-v2上达到71.8（稠密）和71.0（稀疏），优于RzenEmbed等同类模型。该模型在BEIR基准上同样具有竞争力，并在有效性、效率和智能体应用三个维度验证了实用价值。统一稀疏与稠密嵌入为检索增强生成提供了更高效的方案。

### MiniMax H3 量化版上线：INT4/INT8/NVFP4 多格式支持本地部署

社区开发者 Abiray 在 Hugging Face 发布了 MiniMax H3 模型的量化与剪枝权重集合，涵盖 INT4、INT8、Mixed 及 NVFP4 多种格式。该方案针对 16GB 至 24GB 显存的消费级显卡优化，支持在 ComfyUI 等本地环境运行文本、图像、音频到视频的多模态生成。从业者可直接下载对应显存版本的权重文件，降低高性能视频生成模型的本地部署门槛，便于在有限硬件资源下进行实验与应用开发。

### 仅激活 5.1B 参数：inclusionAI 发布 Ling-3.0-flash 混合推理模型

inclusionAI 团队推出 Ling-3.0-flash，这是一款原生混合线性注意力架构模型。其总参数量 124B，但每 token 仅激活 5.1B 参数，通过 Kimi Delta Attention 与 MLA 的交替堆叠及稀疏 MoE 设计，在长上下文效率与计算成本间取得突破。基准测试显示其性能匹敌或超越前代千亿级旗舰。对从业者而言，该模型为生产环境中的复杂 Agent 工作流提供了低算力消耗下的高性能推理新选项，适合部署对延迟敏感的应用。
