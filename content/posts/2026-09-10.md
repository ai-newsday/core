## AuK：30.3亿实例训练的开源语音生成编辑模型，4步推理加速4.5倍

AuK 是一个开源基础模型，用自然语言指令和音频上下文统一语音生成与编辑。团队构建了约 30.3 亿指令‑音频实例和 195 万小时有效监督，覆盖语音生成、内容编辑、增强分离、副语言编辑和声学编辑五类任务。模型结合多模态大语言模型进行语义条件化，以及一个在语音、通用音频和音乐上联合训练的 VAE 进行声学条件化，生成部分采用混合整流流 Transformer，先运行双流 MMDiT 块再进入单流 DiT 块。

## 全双工、可打断、能主动提问：Gander 用一个框架统一感知、对话与 Agent 能力

![](https://arxiv.org/html/2609.08977v1/omni_pic.png)

Gander 是一个端到端模型，将全感知、实时交互与 agent 能力整合至单一框架。它采用小脑-大脑协作架构：小脑负责实时对话，大脑处理复杂推理与高层 agent 任务，两者通过工具调用和 agent 编排运行时持续交互。小脑基于流式 Thinker-Talker 架构，将用户输入与模型输出在 chunk 层压平为有序 token 流，实现低延迟连续交互。模型接收视频、语音、文本等多模态流式输入，用户可随时打断，模型也能主动提供中间反馈或追问。

## RoMem：三行代码让 AI Agent 不再被过时事实误导

![](https://pbs.twimg.com/media/HRw2_R2a8AAd6go.jpg:large)

RoMem 是一个即插即用的 reranker，只需三行代码即可接入现有 agent 系统。其核心思路是「旋转而非删除」——当查询触发过时事实时，RoMem 不会直接抹除旧信息，而是让它在语义空间中旋转出对齐位置，从而避免 agent 基于陈旧知识做出错误回答。对开发者而言，这意味着无需重构记忆存储架构，就能显著提升 agent 的事实准确性。

## Delayer Agent 上线，广告库素材无需 PSD 也可再次分层编辑

![](https://pbs.twimg.com/amplify_video_thumb/2097676819789209601/img/m7Z09q9ryUzttvij.jpg)

Bria AI 推出 Delayer Agent，可将广告库中的旧素材恢复为可分层编辑的构图，即使原始 PSD 文件已丢失。该工具通过直接 API 调用，将文本以可编辑文本和 SVG 两种形式带回，方便修改。对于广告创作人员，这意味着旧广告无需源文件即可重新激活编辑，素材复用率提升，直接通过 API 即可集成到现有工作流中。
