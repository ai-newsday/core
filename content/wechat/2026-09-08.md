## Iris: 397B搜索Agent的SFT-RL Climbing训练法

![](https://arxiv.org/html/2609.04304v1/BrowseComp.png)

研究者推出Iris-mini和Iris-pro两个搜索Agent，分别在35B-A3B和397B-A17B规模上训练。任务从web语料的超链接结构反向构建：在实体图上构造多跳链，将所有非答案实体改写为描述性指代，确保无法通过字符串匹配解题，只保留参考模型闭卷失败但提供证据后可解的问题。训练采用SFT-RL交替爬升，RL阶段的奖励判断器和观察摘要器部署在训练集群内，超长rollout在请求级别中断并从已提交的prefix恢复。

## 因果证据：增强或抑制置信度信号可操控 LLM 回答或弃权

![](https://media.springernature.com/m685/springer-static/image/art%3A10.1038%2Fs42256-026-01293-x/MediaObjects/42256_2026_1293_Fig1_HTML.png)

Kumaran 等人展示了语言模型在决定何时回答或弃权时，可通过增强或抑制内部置信度信号来直接影响其行为。该研究为模型决策机制提供了因果证据，表明置信度能被干预。从业者未来或可借此校准模型不确定性，例如在低置信度时强制弃权以降低幻觉风险。

## 腾讯开源 TeamAI-CLI：把团队知识放进一个 Git 仓库，让每个 Agent 共用同一份手册

![](https://pbs.twimg.com/card_img/2097101712180019200/UddbNxUS?format=jpg&amp;name=orig)

腾讯自今年3月起在内部使用 TeamAI-CLI，现已开源。该工具将团队的技能、规则与文档统一存放在一个 Git 仓库中，所有 Agent 共享同一份手册，变更通过合并请求管理。对从业者而言，这提供了一套可复用的多 Agent 知识协同方案，避免各 Agent 维护独立文档导致的信息孤岛。

## 1.653 秒生成 5 秒视频：NVIDIA Sol-H3 加速 MiniMax-H3 开源上线

![](https://pbs.twimg.com/profile_images/1875100548535574529/VxHk9HyU_400x400.jpg)

MiniMax AI 联合 NVIDIA Sol 团队发布 Sol-H3，这是 MiniMax-H3 视频生成模型的端到端推理加速方案。在单台 8× NVIDIA B300 Blackwell 系统上，模型以 1344×768 分辨率生成 5 秒视频仅需 1.653 秒，推理速度超过视频播放速度。方案已完全开源，并通过 Reactor API 提供在线试用入口，无需本地部署 GPU 即可体验。

#视频生成 #开源模型 #NVIDIA
[4]

## 2.6B 参数夺下 15 分：MiniCPM5 成 4B 以下开源模型榜首

![](https://pbs.twimg.com/card_img/2096953439737778176/tKZZp1TM?format=jpg&amp;name=orig)

OpenBMB 的 MiniCPM5-2B 在 Artificial Analysis Intelligence Index v4.2 上获得 15 分，是总参数低于 4B 的开源权重模型中得分最高。该模型参数量为 2.6B，团队表示优化重点在于 agentic performance 与 token efficiency 的平衡。这一成绩意味着在资源受限场景下，2B 级模型已能在智能表现上追赶更大体量的开源方案。

#MiniCPM #开源模型 #参数效率

## RWKV-7 G1j 开放 SVG 提示词测试，G1k 训练版绘图能力更强

![](https://pbs.twimg.com/media/HRmIY4ua0AAUYWc.jpg:large)

BlinkDL_AI 宣布 RWKV-7 G1j（100% RNN 架构）已开放测试，新增 SVG 提示词功能，用户可通过链接体验模型绘图能力。G1j 尝试绘制细节复杂的鸟类图像时超出当前能力，G1k-training 版本表现略优。该更新为开发者提供了直接测试模型视觉生成能力的入口，便于评估 RNN 架构在图像生成任务中的实际表现。

## Motus2 用单一模型打通预测-评估-策略闭环，实现灵巧操作自进化

![](https://pbs.twimg.com/media/HRkrgTdXMAEZyTK.jpg:large)

Motus2 是一种用于灵巧操作的自我进化通用世界模型。大多数机器人世界模型难以在预测、评估和政策改进之间形成闭环，而 Motus2 通过单一共享模型同时承担策略、模拟器和价值模型的角色，使其能够自主提出动作并持续优化。该架构有望简化机器人操作系统的开发路径，将原本分散的预测、评估与策略模块整合为统一模型。

#机器人 #世界模型 #灵巧操作
[7]

## VoxCPM fine-tune 出土耳其语音，Kahya-TTS 展示开源语音模型潜力

![](https://pbs.twimg.com/profile_images/1503637999535284230/ZflGAHZW_400x400.jpg)

OpenBMB 开源的语音模型 VoxCPM 被开发者 @AlicanKiraz0 用于土耳其语语音合成，创建了名为 Kahya-TTS 的项目。该模型基于 openbmb/VoxCPM2，经过全面 fine-tuning 后能生成流畅、有表现力的土耳其语音。模型名称是为了纪念已故土耳其艺术家 Ayhan Kahya。这展示了开源语音模型在低资源语言上的扩展能力，开发者可直接基于现有模型快速适配新语言。

#语音合成 #开源模型 #土耳其语

## LinkedIn 论文探讨 Agent 记忆能否跨项目移植
