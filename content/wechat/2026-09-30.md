## OpenAI 同日双发：常驻 Agent「dots」+ 1/5 价格的 GPT-6.1 Sol

![](https://images.ctfassets.net/kftzwdyauwt9/3SQQ9jqSm3aytzUPKuNS3X/e30d9ff756987b178e2b141de5c64a35/Art_Card___Landscape___16_9___1920_1080.png?w=1600&h=900&fit=fill)

**dots**：OpenAI 推出 7×24 小时运行的 Agent「dots」，由 GPT-6 Astra 驱动，每个 dot 有自己的云端电脑和浏览器，可通过插件连接 4000 多个应用，在 ChatGPT、Slack、Teams 里对话或直接语音沟通，并会从反馈中学习用户偏好。用户可随时打开 dot 的电脑检查进度，也能授权它操作自己的笔记本。首批向 Pro、Business Premium 和 Enterprise 用户开放，同时预览面向企业、拥有独立身份与权限的「专家 dot」。

![](https://images.ctfassets.net/kftzwdyauwt9/1Xa7inzcCfsGE5aV3QqeN3/4f3689ae92e04b18569f9eaf919e7174/GPT-6-1-Sol_16x9.png?w=1600&h=900&fit=fill)

**GPT-6.1 Sol**：GPT-6 Sol 的升级版，定价为 GPT-6 Astra 标准输入输出价格的 1/5，缓存输入每百万 token 0.10 美元。官方数据显示，它在 DeepSWE v1.1 上与 Astra 持平，成本约为其 1/5；OSWorld 2.0 离线集比 GPT-6 Sol 高 7 个百分点，与 Astra 仅差 2.1 个百分点，适合调用量大的编程和 Agent 场景。

## NaiveAI 开源 Naive-N0.5-Flash：309B MoE，原生 1M 上下文，专攻编程

![](https://huggingface.co/NaiveAI/Naive-N0.5-Flash/resolve/main/assets/coding-benchmarks.png)

NaiveAI 以 MIT 协议开源 Naive-N0.5-Flash，总参数 309B、激活 15.5B，面向编程与 AI 研发。模型基于 MiMo-V2.5 继续预训练 3.25T token，48 层中 39 层滑动窗口注意力（窗口 128）加 9 层 DeepSeek 稀疏注意力（DSA），全网络没有完整注意力层，原生支持 100 万 token 上下文。配套推理系统 NaiveRT 在极速模式下最高可达 2000 token/s。API 定价为每百万 token 输入 0.10、输出 0.40 美元。

## RAGFlow v1.0.0-rc1：用 Go 全面重写，部署更轻

![](https://opengraph.githubassets.com/2367a4bbead4753098ea6247142dbaef6a5a6a3aa7f80a3ef687b527ac0e9c40/infiniflow/ragflow/releases/tag/v1.0.0-rc1)

InfiniFlow 的开源 RAG 框架 RAGFlow 发布 1.0 预览版，核心变化是用 Go 全面重写，资源占用大幅下降，原来的重量级部署改为轻量架构。消息队列从 Redis 换成 NATS，缓存和 checkpoint 改存 Kvrocks，CLI 也改用 Go 实现，Python SDK 不受影响。注意：必须先升级到 v0.27.2 才能迁移，数据迁移不可回滚；DeepDoc 暂时只支持 CPU，本地沙箱已移除，Team/Me 权限模型尚未支持。

## GAGAR：给代码 Agent RL 中"都通过测试"的轨迹再排个高低

![](https://cdn-thumbnails.huggingface.co/social-thumbnails/papers/2609.32577/gradient.png)

代码 Agent 的强化学习通常只用测试通过与否作奖励，GRPO 会给同组所有通过测试的轨迹同样的优势，分不出实现质量高低。GAGAR 把同组轨迹放进共享工作区，由 SFT 训练的 Agentic Grader 对通过测试的候选统一排名，给排名靠后的降权，再按比例缩放以保持优势总和不变，把信用推向更干净、更聚焦的实现。论文在 MiMo-V2.6-Flash（310B）和 MiMo-V2.6-Pro（1.02T）上验证，代码 Agent 表现提升，轨迹长度增长放缓，训练也更稳定。

#强化学习 #代码Agent #GAGAR

## VisionHOPE：视觉骨干网络变成"自我修改"的学习系统，权重同步开源

![](https://arxiv.org/html/2609.33325v1/main2.png)

VisionHOPE 基于 Nested Learning 的自指构造，把视觉骨干网络建模为自我修改的学习系统：模型记住什么和怎么学习，在逐像素扫描中一起演化。五个耦合记忆分别负责存储内容、生成 key/value、控制学习率与记忆保留，作者还给出稳定性匹配的步长控制，证明记忆动力学在每次扫描中不发散。论文同时放出 T/S/B 三档预训练权重，覆盖 ImageNet-1K 分类、COCO 检测分割（Mask R-CNN）和 ADE20K 语义分割。

## 谷歌 Diffusion Controller：给图像生成模型加一个轻量"转向阻尼器"

![](https://storage.googleapis.com/gweb-research2023-media/images/HO_previewImage1.width-800.format-jpeg.jpg)

Google Research 提出 Diffusion Controller，把扩散模型的去噪过程重新表述为连续控制问题，用一套数学框架统一了 classifier-free guidance 这类推理期引导和 LoRA、奖励加权回归等微调方法。它以轻量附加网络的形式挂在冻结的基座模型上，连闭源、限制访问的模型也能用，在人类偏好对齐上超过业界常用方案；可以改动模型权重的完整版本对基线模型胜率达 90%。

## Intern-Decision：0.8B/2B/4B 多模态决策模型，4B 超过 Jev

![](https://pbs.twimg.com/media/HTXhXt6WwAA0NXF?format=jpg&name=large)

魔搭社区介绍 Intern-Decision 系列，面向多模态结构化决策，提供 0.8B、2B、4B 三档，七项决策基准平均分分别为 79.38、84.68 和 90.02，其中 4B 超过 Jev（88.74），概率校准也更好。一次前向即可回答选择、打分、是非题，输出带类型的 JSON 和校准后的概率分布，支持文本状态加最多 8 张图片输入，可用于路由、工具选择和工作流控制。在相同本地环境下平均延迟 34–44 ms，Jev 为 110 ms。Apache 2.0 协议。

## ComfyUI v0.38.0：Qwen Image 2.1 加速，新增混元 Image 3.5 等节点

![](https://opengraph.githubassets.com/c00fa805f5c9f381519b4745c7c76d78bf476b5d99a90a55f10f5461bc394a06/Comfy-Org/ComfyUI/releases/tag/v0.38.0)

ComfyUI 发布 v0.38.0。性能方面：改进 Qwen 2.1 的 KV cache 位置逻辑并编译 Qwen Image 2.1 的 transformer 块，为 ACE-Step 1.5 自回归模型加入 CUDA graphs 与内存编译器，把部分优化移植到 Flux 系列，移除 torchaudio 依赖。模型与节点方面：新增混元 Image 3.5、Seedream 5.0 Flash、GPT-6 Sol/Luna、Claude Opus 5.5 等合作方节点，支持 Ming-Image，模型文件可指定每个块使用的 attention 类型。
