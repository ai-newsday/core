## OpenAI 发布 Dots：主动式助手跨项目、日常任务全天候推进

OpenAI 推出 Dots，定位为主动式助手，可在复杂项目与日常任务中持续运行，让用户在后台工作的同时保持掌控。这相当于为普通用户和职场人提供一个可长期调度的自动化执行层，日常琐事与多步骤项目都可以交给它跟进。OpenAI 试图以此切入个人生产力工具赛道，与市场上已有的任务管理类产品形成差异化。

## GPT-6.1 Sol 推出：智能比肩 Astra，价格仅为其 1/5

OpenAI 推出 GPT-6.1 Sol，定价为 Astra 标准 API 输入输出 token 价格的五分之一，同时提供接近 Astra 的智能水平，适用于编程、电脑操作与职业工作场景。这意味着开发者可以用更低成本在日常 coding 和 agent 任务中调用高性能模型。价格下探至 1/5 的水平，可能重塑现有高端模型的定价格局，成为成本敏感型应用的新选择。

## VisionHOPE 让视觉骨干网络学会自我修改

![](https://arxiv.org/html/2609.33325v1/main2.png)

研究者提出 VisionHOPE，将视觉骨干网络首次建模为自我修改学习系统：模型记住什么与如何学习在逐像素扫描中共同演化。该方法基于 Nested Learning 的自指构造，通过五个耦合记忆存储内容、生成 key/value 表示并控制学习率与记忆保留，且推导出一套稳定性匹配步长控制方案，将自指注入软限与谱范数约束结合，证明其记忆动力学在每次扫描中是非扩张的。

## GAGAR：用 Agent 评分重新分配代码 Agent RL 优势，310B/1.02T 模型验证有效

代码 Agent 的强化学习通常依赖可执行测试给出二元奖励，但 GRPO 会对同一 rollout 组内所有通过测试的轨迹分配相同优势，无法区分实现质量。研究团队提出 GAGAR 框架，保留同时含通过和失败轨迹的组，将所有通过测试的轨迹放入共享工作区，由 SFT 训练的 Agentic Grader 联合检查并排名，然后对低排名轨迹降权，按比例重新缩放其余通过轨迹的优势以恢复总和。

## VisionHOPE 发布：把视觉基础架构变成自修改学习系统

研究者公开 VisionHOPE 系列预训练权重，方法核心是把视觉骨干网络改造成「自修改学习系统」，并随同 arXiv 论文（2609.33325）与 GitHub 开源代码一并放出。提供 T / S / B 三种体量，在 ImageNet-1K 分类、COCO 检测分割（Mask R-CNN）、ADE20K 语义分割上给出层级式预训练 checkpoint。自修改学习机制若能在实际训练中稳定复现，下游项目用现成权重即可跳过从头预训练的阶段。

## RAGFlow v1.0.0-rc1：Go 重写架构升级，资源消耗大幅下降

InfiniFlow 的开源 RAG 框架 RAGFlow 发布 v1.0.0-rc1 预览版，核心变化是用 Go 语言全面重写，大幅降低系统资源消耗，以轻量级架构替代原来的重量级部署模式。消息队列从 Redis 迁至 NATS，缓存和检查点改用 Kvrocks 存储。CLI 同步改为 Go 实现，Python SDK 不受影响。升级路径限定为 v0.27.2 及之后版本，且不可回退。DeepDoc 目前仅支持 CPU，本地沙箱已移除，Team/Me 权限模型尚未支持。

## ComfyUI v0.38.0 发布：Qwen 2.1 加速与多项底层优化

ComfyUI v0.38.0 版本正式发布。本次更新聚焦推理性能与灵活性：改进 Qwen 2.1 的 KV cache 位置逻辑，并编译 Qwen Image 2.1 的 transformer 块；允许模型文件内指定每个块的 attention 类型；新增可处理前后缀的 JsonExtractString 节点；移除 torchaudio 依赖；为 ace step 1.5 自回归模型加入 Cuda graphs 与内存编译器；支持 H3 VAE tiles 混合；

## 309B MoE 加 1M 原生上下文：NaiveAI 开源 Naive-N0.5-Flash 编程专用模型

NaiveAI 开源发布 Naive-N0.5-Flash，一款面向编程与 AI 研发的 309B MoE 模型，激活参数 15.5B。该模型通过滑动窗口注意力（SWA）与轻量级 DeepSeek 稀疏注意力（DSA）混合架构实现原生 100 万 token 上下文窗口，全网络无完整注意力层。

## Intern-Decision 0.8B/2B/4B 三档上线，79.38 到 90.02 递增碾压决策基准

中科院自动化所多语言与媒体理解实验室在 2025 年 7 月发布 Intern-Decision 系列模型，涵盖 0.8B、2B 和 4B 三个参数规模，面向多模态结构化决策任务。三款模型在七项决策基准上的平均分分别为 79.38、84.68 和 90.02，其中 4B 版本以 88.74 分超过同量级的 Jev 模型。该系列为需要多模态输入的结构化输出任务提供了轻量级、可快速微调的选择，降低了企业部署决策类 agent 的门槛。

## OpenResearch 桌面版上线：把 coding agents 变成 research agents

OpenResearch 推出原生桌面应用，覆盖 macOS（Apple Silicon 与 Intel）、Windows（x64）和 Linux（x64 与 ARM）三大平台。官方宣称可将 coding agents 升级为 research agents，让用户从底层工具链到上层研究流程实现端到端自主掌控。该版本适合希望将 AI 编程助手延伸到文献检索、实验设计与论文复现等研究环节的开发者。
