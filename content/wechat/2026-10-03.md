## DeepSeek Harness 桌面版上线，macOS 和 Windows 用户可直接安装

![](https://pbs.twimg.com/card_img/2104967384385945600/r2nTAl_e?format=webp&amp;name=medium)

DeepSeek 官方宣布 DeepSeek Harness 桌面版本已上线，支持 macOS 和 Windows 系统。Linux 用户仍可通过 npm 的 @deepseek-ai/dsh 包获取。桌面版采用打包形式发布，无需配置命令行环境，普通用户可直接安装使用。这对习惯图形界面的开发者降低了体验门槛，无需依赖终端命令即可测试 DeepSeek 模型。

## 报告生成模型 AstaBrief 开源，基于 Asta 架构加速产出

![](https://cdn-uploads.huggingface.co/production/uploads/638e39b249de7ae552d977b5/AdqLEBgtQnaDXKLdylC3l.png)

Hugging Face 博客发布 AllenAI 的 AstaBrief，这是其 Asta 框架下的报告生成模型，当日开源。Asta 是用于生成结构化报告的框架，AstaBrief 侧重速度与报告生成效率，适合需要在较短时间内输出结构化文本的场景。

## Meshy Edit 预告：选区输入文字就能改 3D 模型

![](https://pbs.twimg.com/amplify_video_thumb/2105969339178557440/img/4HsBQlqikvTrWEs3?format=webp&amp;name=large)

Meshy 官方账号透露新工具 Meshy Edit，用户只需选中 3D 模型上的特定区域并输入文字描述，即可实现对局部内容的修改。该功能目前处于预告阶段，尚未公布具体发布日期与技术细节。Meshy 是一家专注于 AI 3D 内容生成的平台，此次更新旨在降低 3D 创作的门槛。

## 无需新采样，SkillRefiner 让 Agent 从历史轨迹自我改进

@askalphaxiv 分享论文介绍 SkillRefiner，该方法完全从历史 agent 轨迹中学习，将过去的错误模式转化为对 Agent 已有技能的针对性修改，无需生成任何新的 rollout。作者同时附上了论文预览链接。目前尚缺具体实验数据与基线对比，方法的实际效果仍需论文正式发布后验证。
